## 3.4 확률
### 01. 확률과 확률변수

```
✅ 관찰한 데이터를 "모집단에서 확률적으로 발생한 값"으로 다루기 위한 출발점
✅ 변수가 이산형인지 연속형인지에 따라 쓰는 분포와 분석 방법이 달라짐
```
‼️확률이란? <br>
→ 발생 여부가 불확실한 사건의 발생 가능성을 숫자로 표현한 것, P(A)로 표기 <br>
→ 0 ≤ P ≤ 1이고, 모든 사건의 확률을 더하면 1

확률변수 : 확률적으로 값이 달라지는 변수 (실제로 취한 값 = 실현값)

이산형 : 범주, 주사위 눈처럼 떨어진 값 <br>
연속형 : 키처럼 이어진 값

<br>

### 02. 확률분포

```
✅ 데이터가 어떤 값을 얼마나 잘 취하는지 보여주는 틀로,
2주차 히스토그램을 수학적으로 설명하는 기반
```
→ 가로축에 확률변수, 세로축에 발생 가능성을 표시한 분포

| 구분| 세로축 |	확률 구하는 법 |
| --- | --- | --- |
| 이산형 | 확률 그 자체	| 각 값의 확률 |
| 연속형| 확률밀도	| 구간의 넓이, 전체 넓이 = 1 |

<sub>**주의사항:** </sub>
<sub>연속형은 한 점의 확률이 0이므로 반드시 범위를 두고 확률을 구함</sub>

<br>


### 03. 기댓값과 분산

```
✅ 분포를 "중심(기댓값)"과 "퍼짐(분산)" 두 숫자로 요약할 수 있음
✅ 평균·표준편차의 이론적 짝, 추정하게 될 모수의 대표적인 예
```
| 구분 | 이산형 | 연속형 |
| --- | --- | --- |
| 기댓값 E(X) | Σ xᵢ·P(X=xᵢ) | ∫ x·f(x)dx |
| 분산 V(X) | Σ (xᵢ−E(X))²·P(X=xᵢ) | ∫ (x−E(X))²·f(x)dx |

→ **기댓값** = 확률적인 평균값 (주사위 E(X)=3.5) <br>
→ **표준편차** = 분산의 제곱근, 0 이상이며 모두 같은 값이면 0 <br>
→ **왜도**(=좌우대칭에서 벗어난 정도), **첨도**(=뾰족함, 꼬리 두께)도 분포를 특징지음

**If**,확률변수가 2개이면? 
- **동시확률분포P(X,Y)** : 두 변수를 동시에 볼 때 확률분포
- **독립** : X, Y 중 한쪽 값이 무엇이든 다른 쪽 확률이 변하지 않음
- **조건부확률P(X|Y)** : Y 값을 알 때 X의 확률
<br>

## 3.5 이론적인 확률분포
### 01. 확률분포와 파라미터
```
✅ 복잡한 데이터를 소수의 숫자(파라미터)로 요약해 표현할 수 있음
✅ 모집단을 "A 파라미터를 가진 B 분포"로 나타냄
```
**파라미터**란? : 확률분포의 형태를 결정하는 숫자  
→ 즉, 파라미터를 알면 분포의 형태를 알 수 있음

<그 외의 분포>: 균등, 이항, 푸아송, 음이항, 지수분포 / 검정통계량 분포

<br>

### 02. 정규분포 
```
✅ 신뢰구간, 가설검정 등 이후 배울 많은 추론통계 방법이 정규분포를 전제로 함
✅ 68-95-99.7 규칙으로 값의 특징을 빠르게 판단 가능 (이상값 판단에도 활용)
```
‼️정규분포 N

→ 통계학에서 가장 자주 등장, 평균(위치)와 표준편차(너비) 2개의 파라미터로 결정 <br>
→ 평균을 중심으로 한 종형, 좌우대칭 <br>
→ 표준정규분포 : N(0, 1)

**표준화 z** : <br>
- 단위와 스케일이 다른 변수 혹은 집단을 같은 기준으로 비교 가능
- "분포 안에서의 위치"로 평가하여 이상값 탐지에 활용
> z = (x - 평균) / 표준편차 → 평균 0, 표준편차 1로 변환
<br>
