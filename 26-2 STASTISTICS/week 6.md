## 6.1 다양한 가설검정 
### 01. 가설검정 방법의 선택
```
✅ 가설검정은 해석 목적과 데이터 성질에 따라 방법이 달라진다
✅ 가설검정 방법을 선택하기 위해서는 데이터 유형, 표본의 수, 양적 변수 분포의 성질 우선적으로 확인
```

**[가설검정의 기본적인 흐름]**  
→ 어떤 가설검정 방법이든 간에 해석의 기본 흐름은 공통적
> 1. 확인하고 싶은 대상에 따라 귀무가설과 대립가서 설정
> 2. 데이터로 가설검정에 필요한 검정통계량 계산
> 3. 귀무가설이 옳다는 가정 하에 통계량의 분포 고려, p값 계산

<br>

**1. 데이터 유형** → 어떤 종류의 데이터끼리의 관계를 보느냐에 따라 방법이 달라진다

| 데이터 조합	| 예시	| 데이터 모양	| 방법 |
| ----- | ----- | ------------- | ------- |
| 양적 × 범주형 |	투약 vs 투약 안 한 집단 혈압	| 막대그래프 | t검정 등 (평균 비교) |
| 범주형 × 범주형	| 백신 접종 여부 vs 감염 여부	| 분할표 | 카이제곱검정 |
| 양적 × 양적	| 몸무게 vs 키 | 산점도 |	상관, 회귀 |

<br>

**2. 표본의 수** → 비교할 집단의 개수에 따라 방법이 달라진다  
| 표본 수	| 하는 일	| 예시 |
| ----- | ----- | ------- |
| 1개 |	집단 하나를 내가 세운 기준값과 비교 | 성인 남성 키 표본의 평균이 175cm인지? |
| 2개 |	집단 둘을 서로 비교	| 실험군 vs 대조군 혈압 |

<br>

**3. 양적 변수의 성질** → 어떤 분포를 취하는가에 따라 방법이 달라진다
| 정규성 유무	| 구분	| 방법 |
| ----- | ----- | ------- |
| 정규성 있음 | 정규분포라고 봄 | 모수검정 |
| 정규성 없음	| 좌우 비대칭, 이상값 있음 | 비모수검정 |
| 등분산성 | 집단 간 분산이 같음 | 일반 t검정, 분산분석 |

**💡용어 정리**  
- 모수 (파라미터) : 분포를 설명하는 숫자 (평균, 표준편차 등)
- 모수검정 : 모집단이 특정 분포를 따른다고 가정하는 검정 (t검정, 분산분석 등)
- 정규성 : 데이터가 정규분포에서 나왔다고 간주하는 성질
- 비모수검정 : 평균이나 표준편차에 기반을 두지 않는 검정
- 등분산성 : 비교하는 집단끼리 분산이 같은 성질

## 6.2 대푯값 비교
### 02. 모수검정의 평균값 비교 - t검정

```
✅ 모집단이 특정 분포를 따른다고 가정할 때 사용하는 검정 방식
✅ 정규성이라는 전제가 있어야만 유의미한 결론을 냄
```

**1. 일표본 t검정** → 어떤 평균값의 모집단에서 표본을 얻었는가를 조사  
<br>
`기본 전제(가설 세우기)`
```
- 귀무가설 "모집단의 평균은 ○○이다."
- 대립가설 "모집단의 평균은 ○○이 아니다."
❗이때 평균값으로는 연구의 배경으로 의미가 있는 값을 고려해야 한다
```

`분석 방법`  
> 평균값 95% 신뢰구간 구하기와 거의 비슷함
> 1. 표본에서 값 계산 : 표본평균, s, n을 사용하여 표준오차를 구한다
> 2. 가설의 신뢰구간 구하기 : 평균값으로 설정한 기준값을 넣어 95% 신뢰구간 구하기
> 3. 실제 표본평균의 위치 확인 : 이를 기반으로 p값을 구한다

→ 결론 내리기 :   
- a=0.05 에서 p≥0.05이라면 모집단 평균은 ○○이 아니라고 말할 수 없다
- a=0.05 에서 p<0.05이라면 모집단 평균은 ○○이 아니다
  - +) 신뢰구간과 α=0.05 가설검정은 같은 계산을 표본평균 쪽에서 보느냐 귀무가설 쪽에서 보느냐의 차이라서 결론이 일치
  
<br>

**2. 이표본 t검정** → 2개 집단의 평균값을 비교

`기본 전제`
```
- 귀무가설 "2개 집단의 평균값은 같다(평균값의 차이=0)."
- 대립가설 "2개 집단의 평균값은 다르다."
```

**[t검정의 특성]**
- 모수검정으로 분류되는 검정이므로 데이터에 `정규성`이 있어야 함
- 일반적인 t 검정에서는 등분산성을 가정함
- 분산이 일치하지 않을 경우 `웰치의 검정`을 이용
- **웰치의 t검정**이란? : 일반적인 t 검정을 개량한 것, 분산이 다르더라도 사용 가능 (정규성 전제)

<br>

**3. 대응 관계가 있는 검정과 없는 검정**
- 대응 없음: 서로 다른 대상의 두 집단 비교 → 이표본 t검정
- 대응 있음: 같은 대상의 전/후 측정 → 차이를 구해 <차이의 평균=0>을 일표본 t검정으로 해석
- 대응 있는 데이터는 대응 있는 검정을 쓰는 편이 제2종 오류가 낮아지고 검정력이 오르는 경향이 있다

<br>

### 03. 모수검정의 평균값 비교 - 정규성/등분산성 조사

```
✅ 모수검정에 있어서 필요한 성질을 조사하는 방법
✅ 검정 방식의 전제 조건을 충족하기 위해 조사
```

**1. 정규성 조사**  
> 모수검정에서는 각 집단의 데이터에 정규성이 전제되어야 함

`조사 방법`
- 시각적 판단 : Q-Q 플롯
- 가설검정 사용 : 샤피로-윌크 검정 = 자주 사용된다
- 이론적 분포와 비교 : 콜모고로프-스미르노프(K-S) 검정

`전제 가설`
```
- 귀무가설 "모집단이 정규분포이다"
- 대립가설 "모집단이 정규분포가 아니다"
```

`결과 해석`
- p≥0.05 = 정규성 있음
- p<0.05 = 정규성 없음
- 그러나 p≥0.05라도 귀무가설이 옳다는 증거는 되지 않음

<br>

**2. 등분산성 조사**
> t검정과 분산분석에서는 데이터가 분산이 같은 모집단에서 획득됐다는 조건 필요

`조사 방법`
- 바틀렛 검정
- 레빈 검정

`전제 가설`
```
- 귀무가설 "2개 모집단의 분산은 같다."
- 대립가설 "2개 모집단의 분산은 다르다."
```

`결과 해석`
- p≥0.05 = 등분산
- p<0.05 = 부등분산
- 그러나 p≥0.05라도 적극적으로 분산이 같다고 주장할 수 없음

<br>

### 04. 비모수검정의 대푯값 비교 
```
✅ 각 집단 데이터에 정규성이 없는 경우에 사용
✅ 평균값 대신 분포의 위치를 나타내는 대푯값에 주목하여 해석
```
→ 평균값을 사용한 모수검정과는 달리 분포의 위치를 나타내는 **대푯값**에 주목하여 해석  

**1. 비모수 버전의 2개 표본 대푯값 비교** → 정규성이 없을 때 2개 집단의 위치(대푯값)를 비교

`기본 전제(가설 세우기)`
```
- 귀무가설 "2개 모집단의 위치가 같다."
- 대립가설 "2개 모집단의 위치가 다르다."
```

- **[윌콕슨 순위합 검정]** : 대표적인 방법
> - 평균값 대신 각 데이터 값의 순위에 기반하여 검정
> - 정규분포를 따르지 않는 데이터의 위치 파라미터를 검정하는 방법
> - 맨-휘트니 U 검정도 같은 방법
> - 두 집단의 분포 모양 자체가 같아야 함: 정규분포가 아니어도 괜찮지만, 분산이 다르면 적절하지 않은 검정

→ 결론 내리기 :
- p≥0.05 이라면 2개 모집단의 위치가 다르다고 할 수 없다
- p<0.05 이라면 2개 모집단의 위치가 다르다

**[분포 모양이 다를 때]**
 → 플리그너-폴리셀로 검정, 브루너-문젤 검정: 2개 모집단의 분포 형태가 같지 않을 때도 사용할 수 있는 비모수검정
❗ 단, 분포 형태가 극단적으로 다르면 제1종 오류 확률이 설정한 α와 달라지므로 주의


### 05. 분산분석
```
✅ 3개 이상 집단의 평균값을 비교하는 방법 
```

**분산분석이란?** → 3집단 이상의 평균값을 비교

`기본 전제(가설 세우기)`
```
- 귀무가설 "모든 집단의 평균이 같다."
- 대립가설 "적어도 한 쌍에는 차이가 있다."
```

`분석 방법`
1. 집단의 차이를 무시하고 모든 데이터로 전체 평균을 계산한다
2. 각 집단의 평균을 계산한다(ex. A, B, C)
3. 각 데이터와 전체 평균의 차이를 두 요소로 분해한다
4. 집단 내 변동: 같은 집단 안에서의 데이터 퍼짐 (원래 존재하는 무작위 오차의 크기)
5. 집단 간 변동: 집단 평균 사이의 차이 (집단 간 차이를 나타냄)
→ 두 변동을 비교하여 검정통계량 F값을 만든다

**💡F값이란?**
```
F = 평균적인 집단 간 혹은 집단 내 변동
```
- 집단 내 변동 = 오차에 따른 변동, 집단 간 변동 = 효과에 따른 변동 → 이 둘을 비교
- 차이가 있다면 집단 간 변동이 크고, 차이가 없다면 집단 내 편차와 같은 정도로 작다
- 귀무가설이 옳다는 가정 아래에서 F값은 F분포를 따른다 (표본 크기와 표본 수에 따라 모양이 조금씩 다름)

`결론 도출`
- F분포에서 관측한 F값 이상으로 극단적인 값이 나올 확률이 p값
- F값이 5% 지점보다 오른쪽에 있으면 α=0.05에서 통계적으로 유의미한 집단 간 차이 有
  -❗ 대립가설이 "적어도 한 쌍에는 차이가 있다"이므로, 어느 쌍에 차이가 있는지는 알 수 없다 → 다중비교 필요

**[분산분석의 특성]**
- 모수검정으로 분류되므로 각 집단의 데이터에 정규성이 있어야 함
- 등분산성 조건도 필요
- 정규성이 없는 집단이 1개 이상이면 분산분석 대신 비모수검정인 크러스컬-월리스 검정 권장
