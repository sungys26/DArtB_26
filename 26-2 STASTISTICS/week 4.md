## 4.2 표본오차와 신뢰구간
### 01.표본오차

```
✅ 무작위 표본을 고르는 데서 발생하는 오차로, 이 오차를 파악해야 보다 정확한 통계적 특성 파악 가능
```


**💡표본오차란?**  
→ 모집단평균과 표본평균 사이에서 발생하는 피할 수 없는 어긋남(오차)  
→ 표본오차는 확률적으로 바뀜

**[큰 수의 법칙]** : 표본크기(n)가 커질수록 표본평균(x̄)이 모집단평균(μ)에 한없이 가까워지는 법칙  
→  즉, 표본 오차가 0에 한없이 가까워진다는 뜻

<img width="593" height="355" alt="image" src="https://github.com/user-attachments/assets/f51abbe8-1e69-4229-a50e-91fda6ca776c" />

- 왼쪽 = 균등분포 / 오른쪽 = 정규분포
- 해당 그래프를 통해 표본 크기가 커질수록 표본평균이 모집단평균과 가까워짐을 알 수 있음

<br>

### 02. 표준오차의 확률분포

```
✅ 어느 정도 크기의 오차가 어느 정도의 확률로 나타는지 알 수 있음
✅ 즉, 오차 그 자체의 특성 파악에 있어 중요
```


**[중심극한정리]**  
→ 모집단의 분포와 상관없이, **표본크기가 커질수록 표본평균의 분포는 정규분포에 가까워진다**  

**원리 이해**  
- 표본평균은 표본에 따라 매번 달라지는 확률변수 → 이를 알기 위해 분포를 파악하고자 함
- 표본의 표준편차는 다음과 같이 구성됨
  - 표준편차 : 모집단 표준편차 / 표본크기의 루트값 (σ/√n)
- 표본크기가 커질수록 표준편차가 작아짐 → 흩어짐이 줄어듬
- 이를 종합해 보면 표본크기(n)이 커질 때 표본평균들의 분포가 정규분포와 가까워진단 원리

<br>

### 03. 추정량

```
✅ 모집단의 성질을 추정하기 위해 사용
```

**💡추정량이란?**  
→ 모집단의 성질을 추정하는 데 사용하는 통계량  
- **일치추정량** : 표본크기 n이 무한대일 때, 모집단의 성질과 일치하는 추정량
- **비편향추정량** : 추정량의 평균값이 모집단의 성질과 일치하는 추정량

**비편향추정량에 대하여**
- 매번 얻을 때마다 확률적으로 다른 값이지만, 평균을 보면 모집단의 성질을 적당히 나타냄
- 즉, 모집단평균을 편향되지 않게 추정함
- 그러므로 _바람직한 추정량_

**비편향표준편차**

<img width="272" height="105" alt="image" src="https://github.com/user-attachments/assets/9a2b2bd6-cbcd-4029-b7fe-fb9d9427bbd6" />

- 표본표준편차의 경우 데이터 퍼짐 정도를 평가할 때는 문제 x
- 그러나 모집단의 표준편차를 과소평가한다는 문제가 있음
- 그렇기에 n-1 로 나누어 값을 보정 = **비편향표준편차**
