## 5.1 가설검정의 원리
### 01. 가설검정

```
✅ 통계학에서 데이터를 분석할 때 가장 많이 사용하는 방법
✅ 이해 없이는 잘못된 검증을 이끌어낼 염려가 있으므로 매우 중요함
```

**💡가설검정이란?** : 데이터에 기반을 두고 분석자가 세운 가설을 검증하기 위한 방법  
→ **p-value**를 계산하여 가설 지지 여부를 판단  <br>

가설을 검정하는 두 가지의 접근법  
- 확증적 자료분석(가설검증형 데이터 분석) : 가설을 검증하는 접근법
- 탐색적 자료분석 : 가설을 미리 세우지 않고 전체 데이터를 탐색적으로 해석

**[가설검정의 개념 이해]**  
- 실험군과 대조군 설정
  - 실험군 : 어떠한 조치를 취한 집단
  - 대조군 : 비교, 대조를 위해 마련한 집단
- 실험군과 대조군의 비교 
  - 비교한 값이 동일 = 가설은 성립하지 않음
  - 비교한 값이 차이 = 가설 성립
 
### 02. 귀무가설과 대립가설

```
✅ 가설검정에 있어 가설 구체화 및 개념 설정을 위한 단계
```

‼️가설검정에서는 상정한 가설을 확인하고자 그 부정 명제인 **귀무가설**을 세우고,  
이 귀무가설이 틀렸음을 주장하는 것으로 **대립가설을 지지**한다는 흐름을 세움

**💡귀무가설이란?** <br>
→ 밝히고자 하는 가설의 부정 명제 (모집단 평균값 동일)  
**💡대립가설이란?** <br>
→ 밝히고자 하는 가설 그 자체 (모집단 평균값 다름)  
<sub><주의사항> : 귀무가설과 대립가설 사이에 존재하는 비대칭성→ 대립가설을 부정하여 귀무가설 지지 불가능</sub>

<br>

**[귀무가설을 활용한 가설검정의 흐름]**  
1. 두 모집단에는 **표본오차가 존재** → 귀무가설이 옳아도 표본평균이 같다고 할 수 없음
   - 즉, 귀무가설이 옳더라도 표본평균에는 차이가 생기고, 이 차이가 귀무가설이 옳을 때도 생기는 것인지,<br>
   아니면 대립가설(원래의 가설)이 옳은 건지 알 수 없음 → **이를 바탕으로 다음 단계 진행**
2. 귀무가설이 옳은 세계를 가정
   - 우선 귀무가설이 옳다고 가정 → 두 모집단 a,b의 평균값이 동일
   - 두 모집단에서 각각 표본을 추출
   - 위의 방법을 여러 번 반복한 뒤, 표본평균의 차이를 히스토그램으로 작성

### 03. p값 (p-value)

```
✅ 귀무가설이 옳은 세계에서 발생하는 확률을 구하기 위한 값
```

**💡p값(p-value)란?** <br>
→ 귀무가설이 참이라고 가정했을 때, 현재 관측된 데이터보다 극단적인 값이 나타날 확률<br>
→ 확률이므로 0 이상, 1 이하의 값으로 표현

<br>

p값이 0.05 이하인 경우 대립가설 채택 → **통계적으로 유의미한 차이가 있음**
p값이 0.05 상회하는 경우 귀무가설 기각할 수 없음 → **통계적으로 유의미한 차이 발견하지 못 함**

**[p값을 활용한 가설검정의 최종 흐름 정리]**
1. 귀무가설이 옳은 세계 가정
2. 현실 데이터가 귀무가설이 옳은 세계에서 어느 정도로 나타나는가를 표시하는 p값 계산
3. p값에 따라 가설 판단

<br>

## 5.2 가설검정 시행
### 04. 유의수준
```
✅ p값의 유의수준을 설정하여 가설 채택 여부를 판단
✅ 가설검정의 개념은 검정기법마다 같지만, p값 계산 방법은 서로 다름 (계산은 R 등 소프트웨어에 맡김)
```
💡유의수준(α)이란? <br>
→ 귀무가설을 기각할지 채택할지 판단하는 경계값 (과학계에서는 보통 0.05 사용)

[이표본 t검정(two-sample t-test)] : 2개 집단의 평균값을 비교하는 검정

귀무가설이 옳다고 가정
표본평균 차이를 표준화하여 t값 계산
s : 2개 집단을 고려한 비편향표준편차
귀무가설이 옳을 때의 t분포에서 실제 t값의 위치 확인
실제 t값 이상으로 극단적인 값이 나올 확률(넓이) = p값
<br>

💡기각역이란? <br>
→ t분포 양끝 2.5%씩, 합쳐서 5%인 영역 (유의수준 5%)
→ 실제 값이 기각역에 포함되면 p < 0.05 → 귀무가설 기각
<sub><예시> t = −2.3이면 t ≤ −2.3일 확률 + t ≥ +2.3일 확률을 더한 것이 p값</sub>

**양측검정 vs 단측검정**
- 양측검정 : 양수·음수 양쪽을 모두 고려 (특별한 이유가 없으면 보통 이걸 사용)
- 단측검정 : 어느 한쪽만 고려해서 넓이를 계산

**신뢰구간과 가설검정의 관계** <br>
→ 95% 신뢰구간이 0에 걸치는지 여부 = p값이 0.05를 넘는지 여부
→ 모집단과 표본 중 어느 쪽을 중심으로 생각하느냐의 차이일 뿐

<br>

## 5.4 제 1종 오류와 제 2종 오류
### 06.
```
✅ 귀무가설·대립가설 중 무엇이 진실인지(2패턴) × 어떤 판단을 내렸는지(2패턴) = 2×2 패턴
✅ 올바른 판단 2가지, 잘못된 판단 2가지
```
💡제1종 오류(위양성)란? <br>
→ 실제로는 차이가 없는데 차이가 있다고 판단하는 잘못
→ 발생 확률 = 유의수준 α
→ 진실(모집단)을 직접 알 수 없으므로, α를 미리 정해두어 제1종 오류 확률을 통제
<sub><예시> α = 0.05 → 귀무가설이 옳을 때 20번 중 1번꼴로 잘못 기각하는 위험을 허용</sub>

💡제2종 오류(위음성)란? <br>
→ 실제로 차이가 있는데 차이가 있다고 말하지 못하고 귀무가설을 기각하지 않는 잘못
→ 발생 확률 = β

**[α와 β의 상충 관계]**
- 한쪽이 작아지면 다른 한쪽은 커짐 (예: α를 0.05 → 0.01로 낮추면 β 증가)
- 일반적으로 α = 0.05 사용
- 표본크기 n이 커지면 α를 고정했을 때 β가 줄어듦

운영진은 새로 바꾼 통계학 과제가 기존 과제보다 만족도가 높은지 확인하고 싶습니다.

1. 귀무가설을 적어 주세요.
2. 대립가설을 적어 주세요.
3. 이 검정에서 비교하고 싶은 값은 무엇인가요?

**Answer**
```
1. 새로 바꾼 통계학 과제는 기존 과제보다 만족도가 같거나 혹은 높지 않을 것이다.
2. 새로 바꾼 통계학 과제는 기존 과제보다 만족도가 높을 것이다.
3. 새 통계학 과제와 기존 과제의 만족도 평균값
```


## 문제 2. p값 해석

가설검정 결과 p값이 0.04였습니다.

1. 유의수준 5%에서는 귀무가설을 기각할 수 있나요?
2. p값이 0.04라는 사실만으로 새 과제가 실질적으로 매우 좋다고 말할 수 있나요?
3. p값 외에 함께 확인하면 좋은 정보는 무엇인가요?

**Answer**
```
1. 유의수준 5%에서는 귀무가설 기각이 가능합니다.
2. p값이 나타내는 것은 통계적 유의성입니다. 판단하는 데 도움이 될 수는 있으나 해당 사실만으로는
단정지을 수 없습니다.
3. 신뢰구간, 표본 대표성 등의 기타 세부적인 정보를 확인하면 좋을 것 같습니다.
```
