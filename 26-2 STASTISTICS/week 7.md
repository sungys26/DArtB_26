# 1단계 개념 정리 ✍️

## 7.2 상관관계
### 01. 피어슨 상관계수

```
✅ 양적 변수 2개 사이의 선형관계가 얼마나 직선에 가까운지를 수치로 나타낸 값 (r)
✅ 흔히 '상관계수'라고 하면 피어슨 상관계수를 말함
```

**💡피어슨 상관계수란?**  
→ 공분산 ÷ (x의 표준편차 × y의 표준편차)  
→ 범위는 −1 ≤ r ≤ 1  
→ 분자(공분산) : x, y가 함께 평균보다 크거나 작으면 양수, 한쪽만 크면 음수

**[부호와 크기 해석]**
- 양의 상관 : x가 커질수록 y도 커짐
- 음의 상관 : x가 커질수록 y는 작아짐
- |r|이 1에 가까울수록 직선에 가깝고, 0이면 무상관

| r 범위 | 해석 |
| ----- | ------------- |
| 0.7 초과 ~ 1 | 강한 상관 |
| 0.4 초과 ~ 0.7 | 중간 정도 상관 |
| 0.2 초과 ~ 0.4 | 약한 상관 |
| 0 ~ 0.2 | 거의 상관없음 |

<sub>분야마다 해석이 달라서 대략적인 기준으로만 봄</sub>

<br>

### 02. 상관계수를 쓸 때 주의할 점

```
✅ r 값만 보고 판단하지 말고 계산 전에 반드시 산점도부터 그려 볼 것
```

**1. 선형관계만 나타낸다**
- 2차·4차 함수처럼 뚜렷한 비선형관계가 있어도 r은 거의 0 (−0.05, −0.03)

**2. 기울기의 크기와는 관계없다**
- 기울기 부호에는 영향을 받지만, 기울기가 커도 r이 커지지 않음 (회귀와 다른 점)

**3. r이 같아도 데이터 모양은 다를 수 있다**
- r=0.32인 산점도가 여러 가지 모양으로 존재

**4. 정규분포를 가정하는 모수적 방법이다**
- 이상값 하나만 추가해도 r이 크게 바뀜 (무상관 데이터가 r=0.81이 된 예)
- 계산 전에 x, y 각각 샤피로-윌크 검정으로 정규성 확인

**5. 종속 관계인 변수끼리 비교하면 가짜 상관이 생긴다**
- 수학 점수(x) vs 수학+과학 합계(y) → y에 x가 들어 있어서 무상관이어도 상관이 나옴
- x와 y/x 처럼 비율로 바꾼 변수도 마찬가지 
- 인구밀도, 인구당 감염자 수 같은 값을 쓸 때 주의

<br>

### 03. 비모수 상관계수

```
✅ x, y 중 하나라도 정규성이 없을 때 사용
✅ 값 대신 순위로 바꿔서 계산하므로 이상값에 강함
```

- **스피어만 순위상관계수 (ρ)** : 순위로 변환한 뒤 피어슨과 같은 식으로 계산
- **켄달 순위상관계수** : 스피어만과 사용 대상이 비슷, 표본크기가 20 미만으로 매우 작을 때 유의성검정에서 더 좋음

<br>

### 04. 상관계수의 가설검정

`기본 전제(가설 세우기)`
```
- 귀무가설 "모집단의 상관계수는 0이다. (무상관)"
- 대립가설 "모집단의 상관계수는 0이 아니다."
```

- 표본의 r은 모집단 상관계수의 추정값
- 무상관 모집단에서도 표본의 r은 0 주변으로 퍼짐 → n=20이면 ±0.47 정도도 나올 수 있음

→ 결론 내리기 :
- p<0.05 → 통계적으로 유의한 상관이 있다
- p≥0.05 → 상관이 있다고 말할 수 없다 (r=0.5여도 마찬가지)
- ❗ 표본크기가 매우 크면 r=0.03처럼 약한 상관도 p<0.05가 될 수 있음 (n=10,000일 때 p=0.002)
  - **p값과 r값을 함께 보고 해석**
- 모집단 상관계수의 95% 신뢰구간도 구할 수 있고, n이 클수록 좁아짐

**💡용어 정리**
- 공분산 : x와 y가 함께 움직이는 정도를 나타내는 값
- 양의 상관 / 음의 상관 : r의 부호에 따른 구분
- 무상관 : r=0
- 비모수 상관계수 : 값 자체가 아닌 순위에 기반한 상관계수

## 7.3 선형회귀
### 05. 회귀분석이란?

```
✅ 설명변수 x와 반응변수 y 사이에 함수(회귀식)를 적용하는 것
✅ 관계성을 알 수 있고, 새로운 x로 y를 예측할 수도 있음
```

- 단순회귀 : 설명변수 1개 / 다중회귀 : 설명변수 여러 개 (8장)
- 회귀모형 : y = a + bx + ε (ε = 확률오차)
- 표본에서 모집단의 a, b를 추정하는 것이 목표
- 선형회귀 : 파라미터에 대해 1차식이면 선형회귀
  - x에 대해 2차식이어도 파라미터에 대해 선형이면 포함
  - 자주 쓰는 이유 : 선형에 가까운 관계가 흔하고, 회귀계수 해석이 쉬움

<br>

### 06. 최소제곱법과 회귀계수

```
✅ 데이터와 회귀식의 차이가 가능한 한 작은 a, b를 구하는 방법
```

`분석 방법`
> 1. 잔차 = 실제 y − 회귀식으로 구한 값
> 2. 잔차를 제곱해서 모두 더한 값 E(a, b)를 계산
> 3. E를 최소로 만드는 a, b를 구함 (E는 아래로 볼록한 2차 함수 → 편미분이 0인 지점)

- ε은 x가 아니라 y에 포함 → 확률변수는 y, x의 분포는 기본적으로 묻지 않음
- **절편 a** : x=0일 때 y의 값
- **기울기 b** : x가 1 늘어날 때 y가 늘어나는 양
- 오차가 x와 무관하고 평균 0, 분산 σ²이면 a, b는 비편향추정량
  - 분산이 일정하면 가장 정밀한(분산이 작은) 최량선형비편향추정량 → 가우스-마르코프 정리

<br>

### 07. 회귀계수의 가설검정과 구간

`기본 전제(가설 세우기)`
```
- 귀무가설 "기울기 b = 0"
- 대립가설 "기울기 b ≠ 0"
```

- 검정에는 오차가 정규분포라는 가정이 추가로 필요 (표본이 충분히 크면 없어도 가능)
- p<0.05 → 통계적으로 b≠0, x와 y가 기울기 b인 선형관계
- ❗ 인과관계까지 말할 수는 없음
- 절편 a는 해석할 필요 없음

| 구분 | 의미 |
| ----- | ------------- |
| 95% 신뢰구간 | 모집단 모형(파라미터)이 포함될 범위 |
| 95% 예측구간 | 새로 얻을 데이터의 95%가 들어갈 범위 (회귀식이 잘 맞을수록 좁아짐) |

→ 두 구간은 헷갈리기 쉬우므로 그래프에 어떤 구간인지 꼭 표기

<br>

### 08. 결정계수 R²

```
✅ 회귀모형이 데이터에 얼마나 잘 들어맞는지 평가하는 지표
✅ R² = 1 − (잔차제곱합 ÷ 반응변수 전체 변동)
```

- 데이터로 설명되는 비율 / 1에 가까울수록 잘 맞고, 0에 가까울수록 안 맞음
- 설명변수가 1개인 선형회귀에서는 R² = r² (상관계수의 제곱)
- 설명변수가 늘면 R²가 커지는 성질 → 의미 없는 변수를 넣어도 좋아 보임
  - **조정 결정계수** : 설명변수 개수로 보정, 잘 안 맞는 모형에서는 음수가 될 수도 있음

<br>

### 09. 오차의 정규성과 등분산성

- 가설검정·신뢰구간을 쓰려면 오차항이 평균 0, 분산 σ²인 정규분포여야 함
- 설명변수나 반응변수 자체가 정규분포일 필요는 없음 (피어슨 상관계수와 다른 점)
- 정규성 : 잔차에 샤피로-윌크 검정
- 등분산성 : x가 변할 때 잔차의 분산이 달라지는지 확인
- 가정이 깨지면 일반화선형모형이나 로그 변환 → 로그 변환 시 회귀계수 해석이 달라짐

<br>

### 10. 설명변수와 반응변수 정하기

```
✅ 상관과 달리 회귀는 x와 y가 비대칭 → 목적에 맞게 정해야 함
```

| 목적 | 설명변수(x) | 반응변수(y) | 주의 |
| ----- | ----- | ------------- | ------- |
| 한쪽으로 다른 쪽을 설명 | 설명하는 변수 | 설명할 대상 | 인과가 아니어도 됨 |
| 인과효과 파악 | 원인 | 결과 | 다른 요인이 같아야 하므로 무작위 개입 실험 필요 |
| 예측 | 예측 근거 변수 | 예측할 변수 | 인과가 없어도 되지만 해석이 어려울 수 있음 |

<br>

## 중요한 개념 다시 정리

### 01. 상관계수

```
개념 이름: 상관계수 (피어슨 상관계수 r)

개념 설명: 양적 변수 2개 사이의 선형관계가 얼마나 직선에 가까운지를 −1에서 1 사이의 값으로 나타낸 것.
부호는 관계의 방향, 절댓값은 관계의 강도를 의미한다.
비선형관계는 잡아내지 못하고 이상값에 민감해서 산점도를 먼저 확인해야 한다.

데이터 분석에서 중요한 이유: 두 변수가 함께 움직이는 정도를 하나의 숫자로 볼 수 있어서 변수 간 관계를 빠르게 파악할 수 있다.
다만 인과관계를 보여 주지 않으므로 표본의 r이라 p값과 함께 해석해야 한다. 단순히 값만 보고 결론을 내릴 수 없다.
```

### 02. 결정계수

```
개념 이름: 결정계수 R²

개념 설명: 회귀모형이 데이터를 얼마나 잘 설명하는지 나타내는 값으로, 반응변수의 변동 중 회귀식으로 설명되는 비율이다.
1에 가까울수록 잘 맞고 0에 가까울수록 안 맞는다.
설명변수가 1개인 선형회귀에서는 상관계수의 제곱과 같다.

데이터 분석에서 중요한 이유: 회귀식을 구했다고 해서 좋은 모형인 것은 아니므로 모형이 얼마나 잘 맞는지 평가할 기준이 필요하다.
설명변수가 많아지면 R²가 커지는 성질이 있어서 변수가 여러 개일 때는 조정 결정계수를 같이 봐야 한다.
```


# 2단계 확인 문제 ✅

## 문제 1. 상관관계 해석

학술제 준비 시간과 프로젝트 완성도 점수의 상관계수가 0.62로 나왔다고 합시다.

1. 상관계수 0.62는 어떤 관계를 의미하나요?
2. 이 결과만으로 "준비 시간이 길어지면 반드시 완성도가 높아진다"고 말할 수 있나요?

**Answer**
```
1. 준비 시간과 완성도 점수 사이에 중간 정도의 양의 상관이 있다는 뜻입니다.
준비 시간이 긴 팀일수록 완성도 점수도 높은 경향이 있습니다.
2. 말할 수 없습니다. 상관계수는 두 변수가 함께 움직이는 선형관계의 강도만 보여 줄 뿐 원인과 결과를 보여 주지 않습니다.
또한 경향일 뿐이라 모든 팀에 반드시 해당하지도 않고, 표본에서 나온 값이라 p값 확인이 필요합니다.
```


# 3단계 데이터 분석형 문제 🔍

## 문제 1. 회귀 결과 읽기

다음은 단순회귀분석 결과입니다.

```text
프로젝트 완성도 점수 = 60 + 3.5 * 주간 회의 시간
R² = 0.40
```

1. 회귀계수 3.5는 어떻게 해석할 수 있나요?
2. R² = 0.40은 무엇을 의미하나요?
3. 위 결과를 바탕으로 운영진에게 전달할 문장을 2문장으로 작성해 주세요.

**Answer**
```
1. 주간 회의 시간이 1시간 늘어날 때 프로젝트 완성도 점수가 평균적으로 3.5점 높아지는 관계가 있다는 뜻입니다.
2. 완성도 점수가 달라지는 정도 중 40%를 주간 회의 시간으로 설명할 수 있다는 뜻입니다.
나머지 60%는 회의 시간 외의 다른 요인 때문입니다.
3. 주간 회의 시간이 1시간 늘어날 때 완성도 점수는 평균 3.5점 높은 경향이 있었고, 회의 시간으로 설명되는 점수 변동은 약 40%입니다.
다만 이 결과만으로 회의 시간이 완성도를 높인다고 단정할 수는 없으므로 다른 요인도 함께 살펴볼 필요가 있습니다.
```


# 4단계 오류 찾기 🚨

아래 문장을 읽고, 통계적으로 부적절한 부분을 고쳐 써 주세요.

> "학술제 준비 시간과 완성도 점수의 상관계수가 양수이므로, 준비 시간을 늘리면 모든 팀의 완성도는 반드시 높아진다."

**Answer**
```
학술제 준비 시간과 완성도 점수의 상관계수가 양수이므로, 준비 시간이 긴 팀일수록 완성도가 높은 경향이 있다.
그러나 상관관계만으로는 준비 시간이 완성도를 높인다는 인과관계를 단정할 수 없고 모든 팀에 반드시 해당한다고 볼 수도 없다.

이유: 상관계수는 변수가 함께 움직이는 경향과 강도만 나타내며, 인과관계를 증명하지 않는다.
상관계수의 크기와 p값, 산점도 등을 함께 확인해야 한다.
```
