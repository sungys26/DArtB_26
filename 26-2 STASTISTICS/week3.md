# 2단계 확인 문제 ✅

## 문제 1. 표본평균의 변동

다트비 8기 전체 25명의 실제 평균 과제 소요 시간이 3시간이라고 가정합니다.  
운영진이 매번 5명씩 무작위로 뽑아 평균 과제 소요 시간을 계산한다고 할 때, 다음 질문에 답해 주세요.

1. 매번 뽑은 5명의 평균은 항상 3시간일까요?
2. 표본을 여러 번 뽑으면 표본평균들은 어떤 값 주변에 모일 가능성이 높나요?
3. 표본 크기를 5명에서 15명으로 늘리면 표본평균의 흔들림은 일반적으로 어떻게 달라질까요?


## 문제 2. 정규분포 감각

어떤 시험 점수가 평균 70점, 표준편차 10점인 정규분포를 따른다고 가정합니다.

1. 80점은 평균보다 몇 표준편차 위에 있나요?
2. 50점은 평균보다 몇 표준편차 아래에 있나요?
3. 50점과 80점 중 평균에서 더 멀리 떨어진 값은 무엇인가요?
