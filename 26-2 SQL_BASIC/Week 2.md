## 2-3. 데이터 탐색

**‼️순서 : FROM → WHERE → SELECT** <br>
```
<작성 예시>
SElECT
Col1 As new_name,
Col2,
Col3
FROM Datatset.Table
WHERE
Col1 = 1 
```
### 01. FROM 문법
```
✅ 어떤 테이블에서 데이터를 확인할 것인가?
✅ 데이터 확인할 테이블 명시
```
입력 방식 : Dataset.Table (BigQuery) / 테이블명만 써도 가능한 경우 有
> - FROM Table1 AS *별칭* → 이름이 너무 길 경우 별칭 지정 가능

### 02. WHERE 문법
```
✅ 만약 원하는 조건이 있다면 어떤 조건인가?
✅ 명시된 Table에 저장된 데이터를 필터링
```
입력 방식 : Col = 1 → 컬럼 1에서 값이 1인 것만 가져오겠다는 조건문
### 03. SELECT 문법
```
✅ 테이블의 어떤 컬럼을 출력할 것인가?
✅ 테이블에 저장된 컬럼 선
```
입력 방식 : Col1 , Col2 , Col3 
> - Col1 AS new_name → 컬럼 1의 내용을 as 뒤에 있는 새로운 이름으로 변경
> - SELECT * → 모든 컬럼을 출력하겠다
> - SELECT * EXCEPT(제외할 컬럼) → 괄호 안의 컬럼 제외
