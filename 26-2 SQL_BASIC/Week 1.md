## 1.1 BigQuery 기초 지식

### 01. 데이터베이스 기본 개념

데이터는 **데이터베이스(Database)** 의 **테이블(Table)** 등에 저장된다.

| 용어 | 의미 |
|---|---|
| Database | 데이터 저장소 |
| Table | 데이터가 저장되는 공간 |

---

### 02. OLTP (Online Transaction Processing)

**거래(트랜잭션)를 처리하기 위해 사용되는 데이터베이스**

#### 특징
- **데이터 무결성**이 중요함
  - 예: 주문을 완료하거나, 하지 않거나 (중간 상태 없음)
- 데이터의 **추가(Insert)** 와 **변경(Update)** 이 빈번하게 발생
- 분석 목적이 아니기 때문에, 대량의 데이터를 다루는 **쿼리 속도는 느릴 수 있음**

#### SQL
- 데이터베이스에서 데이터를 가져올 때 사용하는 언어
- 데이터 관리를 위한 특수 목적의 프로그램(언어)

---

### 03. 테이블에 저장된 데이터의 형태

> 테이블의 형태는 엑셀·스프레드시트와 유사하다.

| 구성 요소 | 방향 | 설명 |
|---|---|---|
| **로우 (Row)** | 가로(행) | 하나의 row = 하나의 고유한 데이터 (⚠️ raw 데이터와 혼동 주의) |
| **컬럼 (Column)** | 세로(열) | 각 데이터의 특정 속성 값 (예: 구매 시간, 구매자 등) |

---

### 04. 데이터 웨어하우스(DW)의 등장

#### 등장 배경
- OLTP는 **속도**와 **분석 기능**이 부족 → 이를 보완하기 위해 **OLAP** 개념 등장

#### OLAP (Online Analytical Processing)
- **분석을 위한 기능**을 제공하는 서비스

#### 데이터 웨어하우스 (Data Warehouse, DW)
- 여러 곳에 흩어진 데이터를 **한 곳에 모아서 저장**하는 저장소

> 💡 **BigQuery = 구글의 OLAP + 데이터 웨어하우스**

---

### 05. 데이터 웨어하우스(BigQuery)의 특징
```
1. 쉬운 난이도 — SQL을 사용해 쉽게 데이터 추출 가능
2. 빠른 속도
3. 앱/웹 데이터 추출 용이
4. DW 사용을 위한 별도 서버 구축 불필요
5. 앱이나 웹에서 Firebase, Google Analytics 4(GA4)를 활용할 경우
6. 적은 비용으로 운영 가능
```
---

### 06. BigQuery 비용 구조 (참고)

> 리전 기준: **US**

비용은 크게 **쿼리 비용**과 **저장 비용** 두 가지로 나뉜다.

#### 💵 쿼리 비용 💵

| 요금제 | 설명 |
|---|---|
| **On-demand 요금제** | 쿼리에서 처리된 데이터 용량만큼 부과 (1TB당 $6.25) — 일반적으로 사용되는 방식 |
| **Capacity 요금제** | Slot 단위로 요금 부과 (슬롯 1개당 시간 단위 요금 부과) |

## 2.1 데이터 활용
### 데이터 활용 과정

1. **어떤 일을 할지 정하기** → **2. 원하는 것 정하기**
   - 1~2번: **문제 정의** (MECE 원칙 적용)
   - 원하는 것 = **지표 정의 (Metric)**

3. **데이터 탐색** (단일 자료 / 다량의 자료)
   > 연결 → 조건(필터링) / 추출 / 변환 / 요약

4. **데이터 결과 검증** ⭐ *매우 중요*
   - 예상과 실제 결과가 일치하는지 확인하는 단계

5. **피드백 / 활용**
   - → 문제가 있을 경우 다시 **3번(데이터 탐색)** 으로 순환

## 🧩 문제 2

이번 강의를 통해 SQL이 왜 필요하다고 느끼는지, SQL을 통해 본인이 어떤 것을 해내고 싶은지를 자유롭게 작성해주세요.

풀이 과정:

```
- SQL이 필요하다고 느낀 이유: 대용량 데이터 처리에 있어 기본적인 언어이며, 기업 실무에서도
자주 사용되는 언어이기 때문에 원활한 분석 능력을 기르기 위해서는 필수적이라고 생각했습니다.
- SQL로 해보고 싶은 일: 넷플릭스, 애플 뮤직, 스포티파이 등 미디어 기업들이 고객 데이터를 통해 맞춤형 알고리즘 및 프로모션을 설정하는 메커니즘을 파악하고 수행해 보고 싶습니다. 
- 앞으로 SQL을 공부할 때 기대되는 점: 실제 실무에서 자주 사용되는 쿼리문을 알고 이를 활용하는 능력을 더 길러 나가고 싶습니다. 
```
