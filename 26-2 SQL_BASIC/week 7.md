## WEEK 2
## 02. FROM , WHERE, SELECT
```
✅ 어떤 테이블에서 어떤 조건으로 어떤 컬럼을 고를지 처리하는 기본 쿼리 문법
✅ 모든 쿼리에 있어 필수적으로 필요한 베이직 문법
```
**💡문법 정의**  
- `FROM` : 어떤 테이블에서 데이터를 가져올 것인지
- `WHERE` : 어떤 조건으로 컬럼을 거를 것인지
- `SELECT` : 어떤 컬럼을 고를 것인지
  - **SQL 실행 순서** : FROM → WHERE → SELECT
 
**활용한 코드**
```SQL
SELECT
  Col1 AS new_name,
  Col2
FROM Dataset.Table AS TB
WHERE Col1 = 1
```
- 테이블은 AS 문법을 통해 별칭을 붙여 편리하게 사용할 수 있다
- SELECT * EXCEPT (컬럼) 을 사용하면 지정한 컬럼을 제외한 나머지 컬럼을 출력할 수 있다

**📌헷갈리는 부분 정리** 
```
- 조건에 쓰는 컬럼과 출력할 컬럼은 따로 생각, 무엇을 WHERE에 넣을지, SELECT에 넣을지 고민해야 한다
- WHERE에서 사용하는 컬럼은 SELECT에 나열하지 않아도 된다
- WHERE은 ORDER BY 이전에 온다
```


## WEEK 3
### 03. GROUP BY, HAVING
```
✅ 분석에 필요한 데이터 요약을 위한 묶기 문법
✅ 조건에 사용하는 WHERE과의 차이 파악
```
**문법 정의**
- `GROUP BY` : 특정한 컬럼 값이 같은 행끼리 묶어 그룹으로 집계
- `HAVING` : 묶은 뒤 집계 결과에 조건을 거는 문법

**활용한 코드**
```SQL
SELECT ANIMAL_TYPE, COUNT(*) AS count
FROM ANIMAL_INS
GROUP BY ANIMAL_TYPE
ORDER BY ANIMAL_TYPE;
```
- 집계 없이 SELECT에 쓴 컬럼은 GROUP BY에 포함해야 한다
- WHERE은 집계 전의 행을, HAVING은 집계 후의 그룹을 거르는 문법이다
- 상단의 코드에 HAVING 문법이 사용되지는 않았지만 만약 사요하게 된다면 집계 함수는 HAVING에서만 쓸 수 있다

---

### 04. 집계 함수 - COUNT, SUM, AVG, MAX, MIN
```
✅ 여러 행을 하나의 숫자로 요약하는 함수로 지표를 만들 때 가장 많이 사용
```
**문법 정의**
- `COUNT` : 개수 / `SUM` : 합계 / `AVG` : 평균 / `MAX` : 최댓값 / `MIN` : 최솟값

**활용한 코드**
```SQL
SELECT MAX(PRICE) AS MAX_PRICE
FROM PRODUCT;
```
- 전체 행을 세고 싶을 때는 COUNT(*)를 활용, 나머지는 NULL을 제외하고 계산한다
- MAX는 숫자뿐 아니라 날짜와 시간 컬럼에도 사용 가능하다

### 06. CAST, SAFE_CAST
```
✅ 데이터 타입을 변환하여 계산이나 비교에서 발생하는 에러를 방지
✅ 보이는 값과 저장된 타입이 다르면 에러 발생하므로 데이터 타입 확인 필수
```
**문법 정의**
- `CAST` : 데이터 타입을 변환하는 함수
- `SAFE_CAST` : 데이터 타입 변환에 실패할 경우 에러 대신 NULL을 반환
  - 사용 예시 상황 : 부울 값이 문자열 ‘true’/’false'로 저장된 경우에 변환이 필요

**대표적 데이터 타입**
> 숫자, 문자, 시간, 날짜, 부울(True/False)

**활용 예시 코드**
```SQL
SELECT
  CAST(1 AS STRING),
  SAFE_CAST("다트비" AS INT64)  -- 변환 실패 시 NULL
```


왜 중요한가: 보이는 값과 저장된 타입이 다르면 계산이나 비교가 틀어지기 때문입니다.
정의: CAST는 데이터 타입을 바꾸는 함수입니다. SAFE_CAST는 변환에 실패하면 에러 대신 NULL을 반환합니다.
학습한 내용: 대표 타입은 숫자, 문자, 시간·날짜, 부울(True/False)입니다. 예를 들어 부울 값이 문자열 ‘true’/’false'로 저장된 경우에 변환이 필요합니다. 문자를 숫자로 바꾸는 것처럼 변환할 수 없는 값에 CAST를 쓰면 에러가 납니다.
활용: 이번 주 문제는 문자열 조건(LIKE, UPPER, LEFT) 위주여서 CAST를 직접 쓴 적은 없습니다. 이 항목은 개념과 예시 위주로 정리하게 됩니다.
예시 코드:

```
개념 이름:
개념 설명:
아직 헷갈리는 점:
```
